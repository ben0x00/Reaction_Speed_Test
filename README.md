# Reaction_Speed_Test

[View the project on GitHub](https://github.com/MLicence/Reaction_Speed_Test#reaction_speed_test)

This web app studies how cognitive load affects reaction speed. Participants complete three reaction-time stages, then view a results chart and download the results as CSV files from the Results section. Use the fullscreen button in the top-right corner for a distraction-free test view.

| Stage | What appears | Participant response | What counts |
|---|---|---|---|
| 1. Green control | Green circle | Press **Space** | Successful green responses |
| 2. Selective response | Red or green circle | Press **Space** for green; do nothing for red | Successful green responses; red is a distractor |
| 3. Three-colour response | Red, green, or blue circle | Press **Space** for green; press **Enter** for blue; do nothing for red | Successful green and blue responses; red is a distractor |
The researcher can adjust stage repetitions and timing settings from the controls menu. At the end of the study, the app provides trial data, summary statistics, and a chart comparing average reaction time, error variance, maximum, and minimum scores between stages.

The results chart uses grouped bars to compare each stage's average reaction time, error variance (standard deviation), maximum, and minimum scores. The summary CSV combines green and blue reaction results into one Stage 3 row; red trials remain accuracy-only.

This app was made for the Week 4 homework of module SCCM5410 at Lancaster University by Team One from the lab session (Grp-HCI-SCCM5410-Lab-P01/09).
